# 项目概述

## 1. 项目背景

### 水下声学传播损失（TL）

**传播损失（Transmission Loss，TL）** 衡量声能在海洋中传播时的衰减量，单位为分贝（dB）。TL 是水下声学的核心参数，直接决定声呐探测距离和水下通信质量。

TL 的计算依赖多个因素：

- **频率**：吸收损耗随频率平方增加（Thorp 公式）
- **几何关系**：声源与接收器的深度、水平距离
- **声速剖面（SSP）**：海水温度、盐度、压力分布决定声线折射路径
- **水深（地形）**：浅水区底部反射次数更多，损耗更高
- **海底特性**：硬质底（岩石/砾石）反射率高，软质底（黏土/淤泥）吸收多

### ASW 仿真中的需求

反潜战（Anti-Submarine Warfare，ASW）仿真系统需要对大量声呐方程进行实时求解：在战术计算、航迹预测、威胁评估等场景中，每秒需要完成数千次 TL 查询。

传统物理模型（Bellhop、RAM、KRAKEN 等）精度高，但计算耗时：

| 模型 | 典型耗时 | 精度 |
|------|----------|------|
| Bellhop（射线追踪） | 0.1 ~ 10 秒/次 | 高 |
| RAM（抛物方程） | 1 ~ 60 秒/次 | 极高 |
| KRAKEN（简正波） | 0.5 ~ 30 秒/次 | 高 |
| **本项目神经网络** | **< 1 毫秒/次** | 待确定 |

在 ASW 仿真中，实时性要求远高于极端精度要求，因此神经网络代理模型是理想选择。

---

## 2. 项目目标

用神经网络替代 Bellhop/RAM/KRAKEN，实现：

1. **推理速度**：单次预测 < 1 毫秒（GPU 批量推理可达微秒级）
2. **输入覆盖**：支持宽频（10 Hz ~ 10 kHz）、全水深范围（20 m ~ 5500 m）、中远距离（1 ~ 200 km）
3. **物理场景多样性**：覆盖 5 种 SSP 剖面类型、5 种地形类型、5 种海底类型
4. **精度目标**：Phase 1 合成数据 val_rmse < 2 dB（物理模型误差量级）

---

## 3. 自动迭代优化思路（借鉴 autoresearch）

本项目架构直接改造自 Andrej Karpathy 的 **autoresearch** 框架，该框架的核心思想是让 LLM Agent 在固定时间预算内自主循环实验，通过 git 分支管理每次探索，用 `results.tsv` 记录进展，"好实验保留 / 坏实验回滚"地迭代。

**原版 autoresearch 的应用场景**：字符级语言模型（NLP 领域，目标是最小化 val_bpb）

**本项目的改造**：将目标域从 NLP 回归任务替换为水下声学 TL 预测（回归任务，目标是最小化 val_rmse dB）

关键保留机制：

- 固定 5 分钟训练时间预算（`TIME_BUDGET = 300`）
- keep/discard 实验循环 + git 分支管理
- `results.tsv` 作为实验记录台账
- Agent 自主运行，人类只需监控，无需干预

## 4. 整体架构：三文件结构

```
autoresearch-tl/
├── prepare.py     # 固定不变 — 数据生成、归一化、评估指标
├── train.py       # Agent 可修改 — 模型架构、超参数、训练逻辑
├── program.md     # Agent 指令 — 实验规则与物理直觉提示
├── pyproject.toml # 依赖管理（uv）
└── docs/          # 本文档集
```

### prepare.py（固定）

- 生成合成 TL 数据集（Phase 1）
- 定义 64 维特征向量布局
- 提供 `FeatureStats`（归一化统计）、`make_dataloader`（数据加载器）
- 提供 `evaluate_rmse`（固定评估指标，**禁止修改**）

### train.py（Agent 可改）

- 定义 `TLNet` 模型（当前为 baseline MLP）
- 训练超参数
- 训练循环与日志输出
- Agent 每次实验都在此文件上进行修改

### program.md（指令文件）

- 实验规则：能做什么、不能做什么
- 物理直觉提示：哪些特征最重要
- 实验循环协议：运行 → 记录 → 保留/回滚

## 5. 分阶段路线图

### Phase 1：合成数据（当前阶段）

**状态**：已实现，可立即运行

- **数据来源**：`prepare.py` 中的解析物理公式生成
- **物理模型**：球面/柱面扩展 + Thorp 吸收 + Lloyd 镜面效应 + 底部反射 + 声道增益
- **样本量**：20 万训练 + 5 万验证
- **目标**：建立 baseline，探索最优网络架构
- **优点**：无需外部软件，数秒内生成数据，可无限扩展
- **局限**：合成公式是物理近似，不含完整波动声学效应

### Phase 2：pyram 集成

**状态**：规划中

- **数据来源**：调用 pyram（Python 版 RAM 抛物方程模型）批量生成
- **物理精度**：比 Phase 1 公式高一个量级，含完整波动效应
- **挑战**：每条样本需要秒级计算，大规模数据集需要计算集群或长时间运行
- **迁移策略**：用 Phase 1 预训练权重作为初始化，Phase 2 微调

### Phase 3：真实测量数据

**状态**：远期规划

- **数据来源**：海上实测声学数据（海试、历史数据库）
- **目标**：将模型泛化到真实海洋条件
- **挑战**：数据稀少、标注困难、环境变化大
- **技术路线**：Phase 2 模型 + 实测数据微调（迁移学习）

## 7. 快速开始

```bash
# 安装依赖
uv sync

# 生成 Phase 1 数据（约 200000 训练样本，耗时 ~30秒）
uv run prepare.py

# 启动训练（固定 5 分钟时间预算）
uv run train.py
```

详细使用说明见 [06-usage-guide.md](./06-usage-guide.md)。
