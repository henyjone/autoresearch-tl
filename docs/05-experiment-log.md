# 实验记录

## 记录说明

本文件用于记录每次 autoresearch-tl 实验轮次的关键决策和结论性总结。详细的逐实验数据记录在各分支根目录的 `results.tsv`（不纳入 git，仅在工作目录保留）。

**results.tsv 格式**（制表符分隔，非逗号）：

```
commit	val_rmse	memory_gb	status	description
```

| 列名 | 说明 |
|------|------|
| `commit` | git commit 短哈希（7 位） |
| `val_rmse` | 验证集 RMSE（dB），崩溃时填 0.000000 |
| `memory_gb` | 峰值显存（GB，精确到小数点后1位），崩溃时填 0.0 |
| `status` | `keep` / `discard` / `crash` |
| `description` | 本次实验的简短描述 |

## 关键决策记录

### 决策 001：选择 MLP 作为 Baseline 架构

**日期**：待填写
**决策**：以 4 层 × 256 维 MLP + GELU + Dropout(0.1) 作为起点

**理由**：
- TL 预测是标量回归任务，输入是固定 64 维特征向量，无序列结构，MLP 是最自然的起点
- MLP 实现最简单，便于快速验证数据管道和训练逻辑是否正确
- 64 维输入对 256 宽 MLP 是合理比例（不过窄也不过宽）
- 4 层深度足以捕捉非线性交互，又不至于梯度消失
- Baseline 一旦确立，所有后续实验的改进都有可量化的参照

**备选方案**：
- 残差网络：更深但更复杂，留作第二轮探索
- 分支编码器：需要更多设计决策，留作理解 baseline 后的改进方向

---

### 决策 002：目标值不归一化

**日期**：待填写
**决策**：模型直接预测原始 TL（dB），不将目标归一化到 [0,1] 或标准正态

**理由**：
- TL 值范围约 10 ~ 200 dB，均值约 60~80 dB，标准差约 20~30 dB
- 不归一化时 MSE 数量级为 dB²，RMSE 直接对应物理误差，便于理解
- 归一化目标会使 val_rmse 的物理含义模糊（需要反归一化才能解读）
- 神经网络的最终线性层可以自然学习到适当的输出缩放

**潜在风险**：
- 若 TL 分布尾部极端值较多，MSE 对大误差的惩罚会过重 → 探索 Huber loss

---

### 决策 003：保留位 [48:64] 用于特征工程

**日期**：待填写
**决策**：特征向量的第 48~63 维预留为零，供 Agent 填入物理导出特征

**理由**：
- 原始特征中 `frequency_hz` 和 `range_km` 是线性存储的，但 TL 对它们的依赖是对数关系
- log₁₀(freq)、log₁₀(range)、Thorp 系数、波长等导出特征预计大幅提升模型精度
- 将这些特征预先计算并存入保留位，比在模型内部计算更高效（一次计算，每步复用）

**实现方式**：可在 `train.py` 的 forward 内部动态计算，或修改 `make_dataloader` 的预处理步骤（注意：不得修改 `prepare.py`）

## 附：物理误差参考

| 误差量级 | 物理含义 | 对 ASW 仿真的影响 |
|---------|---------|-----------------|
| > 10 dB | 量级错误，不可用 | 声呐方程误差极大 |
| 5 ~ 10 dB | 粗略估计，仅供参考 | 探测距离估计误差 2~3 倍 |
| 2 ~ 5 dB | 工程精度，可用 | 探测距离估计误差 1.3~1.8 倍 |
| 1 ~ 2 dB | 良好精度 | 可替代低精度物理模型 |
| < 1 dB | 优秀精度 | 接近 RAM/KRAKEN 精度 |

注：传统物理模型（Bellhop ray tracing）在典型环境条件下自身误差约 1~3 dB，因此对于 Phase 1 合成数据，val_rmse < 2 dB 是合理的工程目标。
